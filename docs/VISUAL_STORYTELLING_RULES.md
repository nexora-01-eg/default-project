# Visual storytelling rules

Each narration beat must record its claim, visual purpose, visible change, emphasis, motion rationale, visual type, and asset evidence. A clip is rejected when its content is not visually verified for that purpose or when foreign UI conflicts with the shot. B-roll cannot be selected from filenames alone.

Use typography for concise claims, diagrams for causal relationships, procedural graphics for abstract concepts, and B-roll only when it illustrates the claim. Change a visual on a meaningful idea or rhythm change, not mechanically per sentence. Motion must clarify hierarchy or energy; hard cuts are preferred unless a transition communicates continuity. Narration timing governs shot and caption timing; unverified word timing must be labeled as an approximation.
