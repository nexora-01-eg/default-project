# Creative Production Pipeline (idea → final, code-driven)

IDEA → Director (`plan_production`, voice-mode aware) → SCRIPT (narrator text) → STORY (`visual_plan.plan_visual_beats`: narration → intent/visual/motion/graphic/transition/audio-accent) → SHOT PLAN (`visual_plan.storyboard` via director shotting, assets scored, foreign-UI veto) → ASSET PLAN (Arsenal-X match→verify→provenance) → VOICE (Piper adapter; VoiceTut slot reserved) → STT/WORD TIMING (whisper adapter) → B-ROLL (trim/cover/punch) → MOTION GRAPHICS (motion_system presets → ASS + camera_push) → KINETIC TYPOGRAPHY (kinetic_captions, STT-true) → INFOGRAPHICS (svgwrite + Pillow cards) → CAMERA MOTION (zoompan pushes) → TRANSITIONS (fades, beat-snapped hard cuts) → SFX (sting, attenuated) → MUSIC (ducked bed) → COLOR (restrained uniform treatment + colour stats) → COMPOSITING (concat/mux) → RENDER → TECH QC (probe/levels/sync/blackframes/frames) → CREATIVE REVIEW (existing reviewer + visual_review additive checks) → BOUNDED REPAIR (≤3 rounds, capability-routed) → MANIFEST (routing log + provenance).

3D/VFX branches exist as contracts only (Blender portable-detect, three.js via future Chromium) and activate solely on director justification. Narrated_tech v1 (82.6 s, reviewer PASS) and stack smoke v2 (43 s) both traversed this pipeline.
